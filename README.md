# LUE-Agent
### 面向城市土地利用效率研究的智能助手

**从研究问题出发，连接数据查询、空间分析与研究报告。**

## 为什么做这个项目

城市土地利用效率研究涉及指标理解、数据可用性核对、边界选择、人口与土地变化计算，以及结果解释。研究者常常需要在不同工具之间切换，并反复检查年份、来源和计算条件。

LUE-Agent 将这些步骤组织到一个研究工作台中：通过对话提出问题，在执行前核对任务，并结合地图、报告与数据查看结果。目标是降低操作与整理成本，同时保留对研究条件和结果来源的检查。

## 研究工作流

**提出问题 → 核对数据与研究条件 → 确认任务 → 执行分析 → 查看地图、报告与数据**

知识问答和数据可用性查询不等于执行计算。正式分析需要用户确认，具体可执行范围取决于部署环境中实际注册的数据、年份和边界。

## 已实现的主要功能

| 模块 | 面向用户的能力 |
| --- | --- |
| 研究对话 | 指标与方法问答、当前数据目录查询、研究问题澄清 |
| 分析任务 | 土地利用效率相关指标分析、任务确认、执行状态与历史查看 |
| 边界输入 | 已注册研究区域、上传边界和 OSM 候选边界确认 |
| 结果工作台 | 地图、报告和数据分区查看，报告导出 |
| 个人记忆 | 上下文用量展示、压缩、个人记忆管理及本人历史研究检索 |
| 多用户 | 独立账号、私有研究空间、服务端权限验证 |
| 管理后台 | 成员账号、角色与启停管理，以及公共数据源目录管理 |

“已实现”不代表任意数据和任务组合均已完成验收。各项范围见[功能说明](docs/capabilities.md)与[验证说明](docs/validation.md)。

## 工作台设计

- 左侧组织导航和最近对话，并提供对话重命名、删除入口。
- 顶部保留紧凑的当前对话标题。
- 主区域并列展示研究助手与研究结果。
- 长对话与报告在各自区域滚动，减少整页无限增长。
- 结果通过地图、报告和数据标签组织。

当前展示稿不附带真实账号截图。界面展示与演示录制方案见[演示指南](docs/demo.md)，后续使用专门演示账号补充。

## 技术概览

前端采用 **React + TypeScript**；服务接口采用 **FastAPI**；后台任务承担分析和报告等较长操作；**PostgreSQL** 保存应用状态，独立文件存储保存用户制品。模型服务、知识资源和科学数据为研究流程提供支持。

详见[模块级架构图](docs/architecture.md)。本仓库不披露内部提示词、具体决策规则或核心算法实现。

## 开发与验证

项目经历了 Streamlit 原型、前后端分离、多用户支持、记忆管理、运行恢复验证和工作台优化等阶段。

已有代表性知识问答、单城分析、上传与 OSM 边界流程的真实模型或 GIS 验证记录；浏览器测试和模拟负载测试另行记录。当前结论不扩展为所有地区、数据组合、GPU 预测或生产容量均已验证。
