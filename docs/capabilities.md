# 功能与适用范围

| 功能 | 已实现内容 | 使用边界 |
| --- | --- | --- |
| 知识问答 | 指标、方法与数据口径解释 | 回答仍需结合实际来源核对，不保证任意问题均正确 |
| 数据查询 | 查询当前注册目录中的可用信息 | 注册不代表每个研究区域都有完整覆盖 |
| 指标分析 | LCR、PGR、LCRPGR 相关研究任务 | 以具体数据来源、年份、边界及计算口径为准 |
| 边界输入 | 注册边界、上传边界、OSM 候选确认 | 外部边界需用户核对，服务可用性依赖外部条件 |
| 结果展示 | 地图、报告、数据与导出 | 不将生成文本作为独立科学证据 |
| 历史研究 | 本人对话、任务与关联结果查看 | 不提供跨成员私有研究内容浏览 |
| 个人记忆 | 上下文展示与压缩、长期记忆管理、历史研究检索 | 记忆可能需要用户纠正，不能替代原始任务结果 |
| 管理后台 | 创建成员、角色调整、启停与密码重置、公共目录管理 | 管理权限不等于读取成员私有聊天、记忆和报告 |

## 典型问题

- “土地消耗率与人口增长率有什么区别？”
- “当前注册了哪些研究城市和年份？”
- “使用当前可用数据分析某研究区域两个年份之间的变化。”
- “只分析人口增长率，并说明使用的人口输入。”
- “查看我之前完成的研究。”

这些是交互示例，不是特定城市或年份的可用性承诺。

## 暂不作为首版展示承诺的内容

- 任意国家、城市或年份均可直接计算。
- 全部 GPU 预测流程已完成真实业务验收。
- 无需人工核对即可形成权威研究结论。
- 团队共享编辑、多租户组织协作或公开在线服务。
- 未经目标机器测量的并发人数与运行性能。
