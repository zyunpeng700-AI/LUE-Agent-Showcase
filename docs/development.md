# 开发历程与方法

以下按建设阶段介绍项目演进，不公开内部设计讨论、原始聊天、提示词或详细实现规则。

| 阶段 | 建设重点 | 形成的成果 |
| --- | --- | --- |
| 原型探索 | 研究任务与数据流程验证 | Streamlit 研究原型 |
| 前后端分离 | 界面与应用服务分工 | React 工作台、FastAPI 接口与后台执行 |
| 多用户支持 | 私有研究空间和管理能力 | 账号、权限、成员及数据目录管理 |
| 记忆管理 | 长对话和研究连续性 | 上下文展示、压缩、个人记忆与历史研究检索 |
| 可靠性验证 | 历史迁移、任务恢复与数据保护 | 隔离环境中的恢复演练和回归测试 |
| 真实业务验证 | 问答、指标分析与边界流程 | 代表性真实模型和 GIS 案例对照 |
| 交互完善 | 提高对话和结果区域利用率 | 紧凑顶栏、侧栏对话管理、面板内滚动 |

## 开发方法

- 先明确业务范围，再调整实现。
- 区分界面行为、应用协议与科学计算变更。
- 通过隔离测试数据验证，避免污染正式研究历史。
- 对模型回答、计算结果与来源分别核对。
- 保留失败与修复记录，限定每次验收结论的适用范围。
