# 界面截图集

拍摄日期：2026-10-14。以下截图来自项目实际 React 界面与隔离的本地测试服务，使用合成账号、对话、研究参数、示例报告和简化边界。后台模型与计算采用测试适配器；本次没有调用真实模型或执行正式 GIS 计算。

截图展示界面布局和交互状态，不作为科学结论、计算精度或线上服务可用性的证据。Alice、Bob 和 admin 均为隔离环境中的演示账号。
