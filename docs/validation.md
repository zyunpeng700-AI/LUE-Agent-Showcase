# 验证方式与当前结论

此页根据项目已有验收记录整理，不代表本次编写展示材料重新执行了全部测试。

## 已有验证

| 类别 | 证据范围 | 不能据此推断 |
| --- | --- | --- |
| 知识问答 | 真实模型、知识检索与代表性问题逐项核对 | 任意提问均正确、所有引用均无误 |
| 单城完整流程 | 真实模型参与任务与报告，真实 GIS 计算，与旧工具数值对照 | 全部城市均通过，或原始数据已得到独立科学认证 |
| 上传与 OSM 边界 | 代表性边界的确认、执行与结果对照 | 所有格式、网络条件及数据质量异常均已覆盖 |
| 浏览器交互 | 工作台、确认、结果展示、权限等交互回归 | 浏览器用例全部同时使用真实模型和科学计算 |
| 用户与记忆 | 隔离、纠正、删除及恢复相关验证；代表性模型样例复核 | 长期记忆永不误提取，或恢复可无条件直接上线 |
| 负载与恢复 | 隔离环境中的模拟负载、数据库和制品恢复演练 | 真实 GIS 吞吐、公开服务容量和生产恢复承诺 |

## 尚需补齐

- 部分数据覆盖、全 NoData、损坏栅格和执行前数据变化等异常。
- 目标部署系统上的独立安装、资源完整性和真实业务验证。
- 多用户真实混合负载与连续运行观察。
- 生产备份、监控、访问入口及恢复流程。
- GPU 与较大范围预测的专项验收。

测试通过只支持相应输入与环境下的结论。空间结果仍受数据分辨率、来源、边界和年份一致性影响。
