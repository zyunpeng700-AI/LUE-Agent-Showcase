# 界面展示与演示指南

已提供[界面截图集](screenshots.md)，使用真实页面与隔离的合成示例数据。当前没有视频；以下脚本仅供未来录制参考，本次不制作视频。

## 建议截图

| 画面 | 要展示的内容 | 准备要求 |
| --- | --- | --- |
| 研究工作台 | 紧凑标题、对话与结果双面板 | 专门演示账号，清理私人历史 |
| 数据查询 | 当前注册数据的实际查询回答 | 核对来源，去掉内部路径 |
| 任务确认 | 区域、年份、指标及待确认状态 | 使用已验证输入，避免暗示无限覆盖 |
| 研究结果 | 地图、报告与数据标签 | 只展示有授权的示例和已核对结论 |
| 个人记忆 | 可查看、纠正或删除的示例 | 使用合成偏好，不展示真实个人资料 |
| 管理后台 | 成员与公共目录管理 | 使用合成用户名，不展示真实人员列表 |

## 三分钟演示脚本

- 0:00—0:25：说明研究目标与本地演示状态。
- 0:25—0:55：查询数据可用性，展示问题与实际回答。
- 0:55—1:25：准备研究任务，核对条件并解释确认步骤。
- 1:25—2:15：打开已经完成且验证过的示例，查看地图、报告和数据。
- 2:15—2:40：展示个人记忆与历史研究。
- 2:40—3:00：说明当前边界和后续试运行计划。

剪辑跳过等待时明确标注；打开历史结果时注明“已完成示例”，不要表现成当场完成计算。录像不展示密钥、账号密码、文件系统路径或内部日志。

## 图片约定

后续图片存放在 assets/screenshots/，使用简短英文文件名，并附中文说明。发布前逐张检查浏览器地址、用户名、侧栏历史、图层版权署名和报告内容。没有准备好的图片不使用空链接或伪造截图补齐。
